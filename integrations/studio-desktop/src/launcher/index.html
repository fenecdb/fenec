fenec studio

Open a database file, or connect to a server.

Files

    The file is opened by a fenec-server this app starts for it and stops when you close the window.

    Servers

      This address is plain http: the token would cross the network unencrypted. Use https:// unless the server is on a network you trust.

      The server must be started with --studio. Its own studio opens in the window, so there is no CORS to set up.
