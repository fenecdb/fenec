Your language

Connect with the PostgreSQL driver you already use, and send vectors with pgvector's library for your language.

Every example on this page is what the drivers run against a real server on each change to fenecdb (make drivers-test). A language not on this list may well work; these are the ones that are tested.

Start a server

fenec-server --file app.fenec --listen 127.0.0.1:5433 --password secret

Then pick your language. Each example makes a collection, writes a document with a vector, and asks for the nearest.

Connect and search

pip install "psycopg[binary]" pgvector numpy
import numpy as np, psycopg
from pgvector.psycopg import register_vector

conn = psycopg.connect("host=127.0.0.1 port=5433 user=fenec password=secret",
                       autocommit=True)
register_vector(conn)

conn.execute("create collection if not exists docs "
             "(title text, embed vector<3> @hnsw(cosine))")
conn.execute("put docs {title: %s, embed: %s}",
             ("Night at the oasis", np.array([0.1, 0.2, 0.3], dtype=np.float32)))

rows = conn.execute("get docs select title near embed %s limit 5",
                    (np.array([0.1, 0.2, 0.3], dtype=np.float32),)).fetchall()

dotnet add package Npgsql

    "Host=127.0.0.1;Port=5433;Username=fenec;Password=secret;Database=fenec");

await using var db = builder.Build();
await using var conn = db.CreateConnection();
conn.Open();

new NpgsqlCommand("create collection if not exists docs (title text, embed vector<3> @hnsw(cosine))", conn)
    .ExecuteNonQuery();

using (var put = new NpgsqlCommand("put docs {title: $1, embed: $2}", conn))
{
    put.Parameters.AddWithValue("Night at the oasis");
    put.Parameters.AddWithValue(new Vector(new float[] { 0.1f, 0.2f, 0.3f }));
    put.ExecuteNonQuery();
}

using var near = new NpgsqlCommand("get docs select title near embed $1 limit 5", conn);
near.Parameters.AddWithValue(new Vector(new float[] { 0.1f, 0.2f, 0.3f }));
using var rows = near.ExecuteReader();

No driver at all

Any language that can send an HTTP request can use fenecdb: start the server with --http and post a query.

curl -X POST localhost:8080/query \
  -d '{"query":"get docs select title near embed $1 limit 5","params":[[0.1,0.2,0.3]]}'

Python has a small client for it, pip install fenecdb (HTTP endpoint).

Details: what each driver is tested for

The full list of what each driver and library is held to — prepared statements, binary rows, transactions, COPY, the catalog queries each sends on its own — is on PostgreSQL server. Two drivers needed the server to change before they could connect at all: Npgsql opens every connection with catalog queries that start with a comment, and Ruby's pg learns its types by joining pg_type to pg_proc. Both run in CI now, as every language here does, so a change that would break one is caught before it ships.
