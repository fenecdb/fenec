Everything you reach for in a database

A document database first. Search by words and by meaning is built in, not bolted on.

  • DocumentsRecords with typed fields. Add, change and remove them in one line.
  • IndexesInstant lookups and range queries on the fields you choose.
  • AggregatesCounts, sums and averages, grouped and sorted.
  • Related dataEach record arrives with its related records, in one query.
  • Atomic batchesSeveral writes land together, or none of them do.
  • Full-text searchRanked keyword search, for Turkish, Chinese, Japanese and Korean too.
  • Vector searchFind by meaning, and blend it with keywords.
  • Sorting by languageNames in the order your language puts them.
  • Live dataEvery change as a stream. Screens that update themselves.
  • BackupsEncrypted, continuous, restored to any moment.

Run all of it in a web page, in Rust, or over HTTP from any language. The whole query language fits on one page.

Security

Every request passes the same checks, from the login to the disk.

  • Sign in safelyA token for the server, a read-only token for a dashboard. Repeated failures slow down.
  • Your sign-in providerTokens from Auth0, Clerk or Firebase work as they are. Keys rotate without a restart.
  • Each user, their own rowsEveryone sees only the rows they may; writing someone else's is refused.
  • A record of who did whatEvery refusal, schema change and admin action is written to a log.
  • Encrypted backupsBackups and archives are sealed with a key you hold, and so are copies kept in the browser.
  • Nothing borrowedNo third-party code in the engine or the server: nothing upstream to compromise.
